# Introduction

Keeps off-screen contextual information in "sticky" headers (using [posframe](https://github.com/tumashu/posframe)), at the top of the window, to simulate the sticky scroll feature found in other editors like Xcode. Modified (simplified) from [treesitter-context](https://github.com/zbelial/treesitter-context.el). with

![demo](./sticky.gif)

Language support

- C
- C++
- Python
- TypeScript / TSX
- JavaScript
- Rust
- Go
- Java
- YAML
